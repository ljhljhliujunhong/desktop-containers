我想开发一款 Windows 桌面图标分组管理工具。

请你根据下面的产品需求，自主完成产品设计、工程结构设计和实现。

重要要求：

不要被我指定技术栈，我只描述产品需求。
具体使用什么语言、框架、Windows API、渲染方案、数据存储方案、桌面集成方式等，由你根据稳定性、性能、体积、开发复杂度和后期维护成本自行选择。

产品的核心目标是：

让 Windows 用户可以直接在桌面上创建“应用分组容器”，把散乱的桌面应用图标收纳到不同容器中。

它不是传统文件夹。

传统文件夹需要：
打开文件夹 → 找到应用 → 双击启动

而我的容器应该是：
应用图标直接显示在桌面容器内部 → 用户直接双击图标 → 启动应用

也就是说，这是一种“始终展开的桌面应用分组容器”。

\==================================================
一、核心产品概念
========

在 Windows 桌面上，用户可以创建多个“桌面容器”。

例如：

┌─────────────────────────────┐
│ │
│ ChatGPT Claude Gemini │
│ │
│ Cursor Dify ComfyUI │

AI 应用
开发工具
设计工具
办公

影音
学习
等等。

每个容器内部直接展示应用图标。

用户不需要打开容器。

直接双击容器中的图标即可启动对应应用。

\==================================================
二、桌面容器核心功能
==========

1. 创建容器

用户可以在桌面创建新的容器。

创建后可以：

命名
移动
调整大小
删除
修改外观

例如：

AI 应用
开发工具
游戏
办公软件

创建过程尽量简单。

目标是让用户几秒钟之内就可以创建一个新的桌面分类。

***

2. 容器可以自由拖动

用户可以拖动整个容器。

拖动容器时：

容器内部所有应用图标一起移动。

用户不需要一个一个重新排列图标。

这也是这个产品最核心的价值之一。

***

3. 容器可以调整尺寸

用户可以自由调整容器宽度和高度。

例如：

小型容器
中型容器
大型容器
长条形容器
方形容器

当容器尺寸变化时：

内部应用图标应该自动重新排列。

***

4. 应用图标自动布局

容器内部的图标应该自动排列。

例如：

一行 4 个
一行 5 个
两行
三行

容器变宽时可以自动增加一行显示数量。

容器变窄时自动换行。

整体视觉应该整齐。

但同时允许用户手动调整图标顺序。

***

5. 把桌面应用拖入容器

用户应该可以把 Windows 桌面上的应用快捷方式直接拖入容器。

例如：

把 ChatGPT 拖到“AI 应用”。

把 VS Code 拖到“开发工具”。

把 Photoshop 拖到“设计工具”。

操作方式应该符合 Windows 用户直觉。

***

6. 容器之间移动应用

用户可以：

把应用从 A 容器拖到 B 容器。

例如：

Cursor

从：

AI 应用

拖到：

开发工具

***

7. 把应用移出容器

用户也应该可以把应用从容器拖回桌面。

也可以提供：

右键 → 移出容器

应用从容器移出以后，恢复为普通桌面图标。

***

8. 双击启动应用

这是非常重要的交互。

用户不需要：

先双击容器
再打开一个窗口
再找到应用

而是：

直接双击容器内部的应用图标

立即启动应用。

整个容器应该始终保持“展开状态”。

***

9. 应用名称

应用图标下方可以显示名称。

例如：

ChatGPT

Claude

Gemini

Cursor

用户可以选择：

显示应用名称
隐藏应用名称

***

10. 图标大小

用户可以调整：

小图标
中图标
大图标

最好也支持连续尺寸调整。

二十七、产品原则
========

开发过程中请始终遵守几个原则：

第一：

它是桌面的增强，而不是桌面的负担。

第二：

启动应用的操作次数不能增加。

第三：

整理应用必须比 Windows 原生桌面更方便。

第四：

视觉必须年轻、漂亮、可爱，但不能牺牲效率。

第五：

尽量减少用户学习成本。

第六：

用户第一次看到它，就应该能理解怎么使用。

第七：

稳定性比花哨功能更重要。

第八：

软件应该保持轻量。
